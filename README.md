# つながり手帖 — noteのフォロー整理・フォローバック確認

noteのフォロー・フォロワーを見やすく整理し、取得できた情報からフォローバックや片思いを確認できる、無料の非公式Chrome拡張です。残す人・保留・メモで一人ずつ見直せます。解除はnoteで手動操作。

**紹介ページ: https://nagasaw.github.io/tsunagari-techo/**

## 入れ方（β版・Chromeウェブストア未掲載）

1. [tsunagari-techo-beta.zip](downloads/tsunagari-techo-beta.zip) をダウンロードして解凍
2. Chromeで `chrome://extensions` を開き、右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」で、解凍したフォルダを選ぶ
4. noteにログインして自分のプロフィールを開き、拡張アイコンから「情報を更新」

## 扱う情報

- 保存先は利用中のブラウザのローカル領域だけ。運営者のサーバーへの送信、広告、アクセス解析はありません
- パスワードやCookieの値は読み取り・保存・外部送信しません
- 権限は `activeTab` と `scripting` のみ（全サイト常時アクセス・閲覧履歴・Cookie APIは要求しません）
- 自動フォロー・自動解除・メッセージ送信の機能はありません

詳しくは [使い方とプライバシー](privacy.html)。

## 取得の限界

非公式の読取機能です。確認したAPIは20人×50ページまでで、全員を取得できない場合があります。総数と取得件数は別々に表示します。過去の正確なフォロー日は取得せず、初回確認日を保存します。「今回は未確認」は解除済みという意味ではありません。

## 提供状況

note株式会社による提供・承認を示すものではありません。noteの仕様変更によって利用できなくなる場合があります。ストア公開前の検証段階（β 0.2.0）です。
